# KING AI Global Intelligence — Public Agent Contract

This repository is an intentionally public, sanitized delivery surface.

Automation may use only public information already present in this repository, official public product pages, or clearly attributable public sources. Private implementation, collection, scoring, deployment, infrastructure and operational details are outside this repository's disclosure boundary.

## Mandatory rules

- Never name, link to, enumerate or infer private repositories or private source locations.
- Never publish credentials, tokens, signing material, private keys, database connection details, internal host paths, infrastructure addresses, ports, privileged commands, private APIs, unpublished collection logic or confidential operational data.
- Keep source provenance and confidence visible; missing data must remain missing rather than being invented.
- Keep public datasets sanitized and provider-neutral.
- Do not convert an internal implementation fact into a public product claim without independent public-safe approval.
- Run the repository validation workflow before accepting a public change.

Public content may describe outcomes, methodology, provenance, limitations, product value and approved commercial/public status. It must not expose the private machinery used to produce those outcomes.
