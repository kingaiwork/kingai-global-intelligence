Licensing rule

If a source has restrictive or noncommercial licensing, KINGAI stores only what is legally publishable and keeps the adapter disabled until the intended use is compatible.

授权规则

如果来源存在非商业或其他限制性授权，KINGAI 只公开法律和许可允许发布的内容；在用途不兼容时保持适配器关闭。

Access rule

KINGAI does not bypass authentication, paywalls or platform access controls. APIs requiring keys or approval stay disabled until authorized credentials are configured.

访问规则

KINGAI 不绕过登录、付费墙或平台访问控制。需要 API Key 或平台批准的来源在获得合法凭据前保持关闭。
